# Portfolio · Paula Atienza

Static site (HTML + CSS + JS, no build step) rebuilt from https://paulapam.framer.website/.
Ready for GitHub Pages: enable Pages on the `main` branch (root folder).

- `index.html` – content
- `styles.css` – styles (colors and type scale taken from the Framer tokens)
- `script.js` – mobile menu, copy-email button, IKEA projects carousel, logo marquee, readings carousel, draggable fridge magnet letters
- `assets/` – everything downloaded from Framer, so the site no longer depends on framerusercontent.com
  - `fonts/` – PolySans Median, PP Neue Montreal, Neue Montreal, Graphik, Opening Hours Sans (Google Sans Flex loads from Google Fonts)
  - `video/` – project videos
  - `books/`, `img/` – book covers, photo, icons, social image
  - `logos/`, `fridge/` – SVGs exported from the Framer page

Note: PolySans, PP Neue Montreal, Neue Montreal and Graphik are commercial fonts. Check that your licence allows self-hosting them on a public site.
